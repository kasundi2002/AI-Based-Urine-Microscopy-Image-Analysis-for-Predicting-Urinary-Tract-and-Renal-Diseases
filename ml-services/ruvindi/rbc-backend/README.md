# RBC Morphology Analysis Backend

This repository contains the backend implementation for an AI-based urine microscopy system
to detect red blood cells (RBCs), classify them as isomorphic or dysmorphic, and predict
hematuria origin (glomerular vs non-glomerular).

## Features
- Automatic RBC detection from raw microscopy images
- Morphology classification using EfficientNet-B2
- RBC counting (iso vs dys)
- Hematuria origin decision logic
- FastAPI-based backend

## Tech Stack
- Python
- FastAPI
- PyTorch
- OpenCV
- EfficientNet (timm)
